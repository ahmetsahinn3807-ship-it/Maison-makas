# Maison Makas (müşteri)

Müşterilerin salon bulup randevu aldığı uygulama. Paket adı: `com.maisonmakas.musteri`.

- `lib/ekranlar/acilis_ekrani.dart` — açılış: kemer çizilir, marka belirir; TR / EN / DE
- `lib/ekranlar/onizleme_ekrani.dart` — ilk derleme sayfası; 5 görünüm ve vurgu rengi canlı değişir
- `lib/gorunum.dart` — seçilen palet, vurgu ve dil
